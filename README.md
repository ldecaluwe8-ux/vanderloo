# VANDERLOO – landingspagina

Live: GitHub Pages (zie de link in het verslag).

Statische pagina (HTML, CSS, JS) voor de awareness-campagne van VANDERLOO, gebouwd met Claude Code.

- `index.html` wordt gemaakt door `06_Landingspagina/build.py` uit `src/template.html` (logo + MailerLite-embed worden ingevoegd).
- `styles.css`: huisstijl Starlit Garden, rustige lichte versie (Haze/Starlight, rechthoekige foto's, Bebas Neue gespatieerd).
- `main.js`: zachte animaties bij het scrollen.
- Overige bestanden (alles in één map, zoals op GitHub): Firefly-video, Weave-lifestylebeelden, logo en lettertypes (Bebas Neue, Italiana, Karla; SIL Open Font License, zelf gehost).

Fictief merk, schoolproject Creative Automation 2026.
